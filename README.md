# Supermercado
¿Qué es este proyecto? Este es uno de los proyectos que más disfruté hacer porque me permitió unir lo que aprendí en la carrera con la realidad de un negocio. Desarrollé un software integral en Java para gestionar las operaciones diarias de un supermercado, pensando siempre en que fuera fácil de usar para el empleado.
Lo que logré con este software:
Control Total de Inventario: Diseñé un catálogo dinámico que muestra precios y stock en tiempo real (como se ve en la sección de "Catálogo"). El sistema te avisa cuántas piezas quedan de cada producto.
Flujo de Venta Completo: Creé un "Carrito de compras" funcional donde puedes agregar productos, ver el subtotal y procesar el pago, ya sea en efectivo o con tarjeta.
Logística y Devoluciones: Agregué un módulo de "Envío a domicilio" para capturar datos del cliente y una sección de "Devoluciones" por folio, para que el negocio no pierda el orden después de la venta.
¿Por qué me sirvió hacerlo? Aunque parece un sistema sencillo, me ayudó a pulir mucho mi lógica de programación y el manejo de eventos en Java. Me enfoqué en los detalles: desde que el login fuera seguro hasta que la interfaz fuera limpia y no confundiera al usuario.

Tecnologías que usé:
Lenguaje: Java (Swing para la interfaz).
Lógica: Programación Orientada a Objetos para el manejo de productos y carritos.

Diseño: Creación de marca e iconos personalizados para darle una identidad profesional al negocio.
